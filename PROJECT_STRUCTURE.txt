🔌 Backend Integration

Your IBM WatsonX backend should provide:

1. POST /api/analyze
   Input: Contract file (PDF/DOCX)
   Output: { job_id, status }

2. GET /api/status/{job_id}
   Output: { status, progress, current_agent, agent_index }

3. GET /api/results/{job_id}
   Output: { risk_score, entities, clauses, debate, strategy }

4. GET /api/report/{job_id}
   Output: PDF file (bytes)

To connect your backend:
1. Update WATSONX_API_URL in .env
2. Switch client in app.py line 139:
   FROM: client = MockWatsonXClient()
   TO:   client = WatsonXClient()
